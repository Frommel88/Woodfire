WOODFIRE REZEPTBUCH - Pro Connect XL (OG901EU)

Inhalt: 250 offline gespeicherte Rezeptvarianten (25 Basisgerichte x 10 Würzvarianten), 250 lokale SVG-Illustrationen, Einkaufsliste, Favoriten, Suche, Portionsrechner und grobe Kalorienschätzung.

WICHTIG: KEINE 250 QUELLENVALIDIERTEN REZEPTE. Keine echten Speisefotos. Temperatur-/Zeitangaben sind unverifizierte Vorschläge und müssen mit der Originalanleitung, Lebensmittelthermometer und praktischen Tests überprüft werden. Es handelt sich um einen funktionalen Prototyp.

INSTALLATION:
1. ZIP entpacken.
2. Ordner auf einen HTTPS-Webspace laden (z.B. GitHub Pages). Nicht einfach die index.html per Datei-App öffnen: lokale Browser-Sicherheitsregeln blockieren dann JSON und Service Worker.
3. Mit Chrome auf Android die HTTPS-Adresse öffnen und über Menü 'Zum Startbildschirm hinzufügen' / 'App installieren' wählen.
4. Einmal vollständig online laden und Installation abschließen; danach Offline-Funktion testen.
